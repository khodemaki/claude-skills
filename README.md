# Claude Skills

Task-focused skills for Claude. Each skill is a folder with a `SKILL.md` that teaches Claude one job well.

</div>

## Skills

| Skill | What it does |
|---|---|
| [debug-and-fix](debug-and-fix) | Finds the root cause of bugs in HTML, CSS, JavaScript and Python and gives a minimal, targeted fix |
| [clean-code-refactor](clean-code-refactor) | Cleans up and simplifies working code without changing its behavior |
| [professor-style-teaching](professor-style-teaching) | Explains any topic like a warm, patient university professor |
| [online-store-builder](online-store-builder) | Builds online store pages, carts and SEO with structured data |

## How to use

Each skill folder contains a `SKILL.md` file: a short header (name and a description that tells Claude when to use it) followed by the instructions. In the Claude app, upload the skill folder as a zip from the skills section of your settings. In Claude Code, copy the folder into your skills directory.

## Status

These skills are written by hand and have not been through formal evaluation yet. Issues and improvements are welcome.
